TAMASHA BAR & GRILL WEBSITE
============================

1. Extract the whole ZIP folder.
2. Keep index.html and the images folder together.
3. Double-click index.html to preview in Chrome.
4. The phone and WhatsApp buttons use the number supplied: 0711 831769.
5. The booking form prepares a WhatsApp enquiry; it does not automatically confirm reservations.
6. Gallery images are cropped from the screenshots supplied in chat. Since the screenshots were collages, some crops may need replacing with original photo files for best quality.
7. For Netlify, upload the index.html file and the complete images folder together.
